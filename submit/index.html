ส่งข้อมูลเข้าสู่ระบบ

ศูนย์ HPC และวิศวกรระบบสามารถส่งข้อมูลระบบ สถิติ กิจกรรม หรือเหตุการณ์ในไทม์ไลน์ เข้ามาได้ผ่าน GitHub ข้อมูลทั้งหมดเป็นสาธารณะและตรวจสอบย้อนกลับได้

วิธีที่ 1 — กรอกฟอร์ม (ง่ายที่สุด)

กรอกข้อมูลด้านล่าง ระบบจะสร้าง GitHub issue พร้อมข้อมูลให้อัตโนมัติ ทีมดูแลจะตรวจสอบและนำขึ้นเว็บไซต์

ข้อมูลที่ส่งจะกลายเป็น GitHub issue สาธารณะ กรุณาอย่ากรอกข้อมูลส่วนบุคคล รหัสผ่าน คีย์ หรือข้อมูลภายในที่ไม่ต้องการเปิดเผย
