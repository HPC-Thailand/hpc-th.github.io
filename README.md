_The history and landscape of high performance computing in Thailand._

- [ ] บุคคลที่มีส่วนเกี่ยวข้อง
- [ ] แนวทางการพัฒนา

- [x] เป็นแหล่งอ้างอิงข้อมูลให้กับผู้ที่สนใจ — [คลังเอกสารอ้างอิง](https://hpc.in.th/reference/) 28 รายการ

## เป้าหมาย

เนื่องจากการพัฒนากำลังคนทางด้านวิศวกร นักวิจัยและดูแลระบบ HPC โดยเฉพาะ HPC System Engineer เป็นส่วนสำคัญในการพัฒนาและดูแลบำรุงรักษาระบบ HPC

จำเป็นต้องอาศัยระยะเวลา

## ข้อมูลทุกอย่างอยู่ใน `data/`

หน้าเว็บอ่านข้อมูลจาก JSON โดยตรง — ไม่มี generator, ไม่มี framework
เพิ่มระบบใหม่ = เพิ่ม object ใน `data/systems.json` แล้วเปิด PR

ทุกข้อความที่ผู้ใช้เห็นเป็น object สองภาษา:

```json
{ "th": "ข้อความภาษาไทย", "en": "English text" }
```

ตรวจความถูกต้องก่อน push:

```bash
node tools/validate-data.mjs
```

GitHub Actions รันคำสั่งนี้อัตโนมัติกับทุก PR ที่แตะ `data/`

## ที่มาของข้อมูลไทม์ไลน์

เนื้อหาไทม์ไลน์เรียบเรียงจากสไลด์ "ประวัติศาสตร์ HPC ในประเทศไทย" 10 หน้า
ซึ่งเก็บไว้ที่ `historical/page png/` และแสดงเป็นแกลเลอรีท้ายหน้าแรก

ปี พ.ศ. ในสไลด์ต้นฉบับมีคลาดเคลื่อนบางจุด (เช่น 1995 → พ.ศ. 2537, 1997 → พ.ศ. 2506)
เว็บไซต์จึงคำนวณ **พ.ศ. = ค.ศ. + 543** เสมอ แทนการคัดลอกค่าจากสไลด์

## คลังเอกสารอ้างอิง

ไฟล์ต้นฉบับอยู่ใน `reference/docs/` และรายการที่แสดงบนเว็บอยู่ใน `data/reference.json`
เพิ่มเอกสารใหม่ = วางไฟล์ลงโฟลเดอร์ แล้วเพิ่ม object หนึ่งตัวในไฟล์ JSON

ข้อควรระวังเรื่องขนาดไฟล์ — **GitHub ปฏิเสธไฟล์ที่เกิน 100 MB** และ GitHub Pages
จำกัดทั้งไซต์ที่ 1 GB เอกสารที่ใหญ่เกินไปให้ใช้ `"url"` ชี้ไปต้นฉบับแทน `"file"`
เช่นรายงานประจำปีของ e-Science (ฉบับปี 2013 ขนาด 615 MB) ที่ลิงก์ไปยัง
[หน้าดาวน์โหลดของ e-science.in.th](http://www.e-science.in.th/%e0%b8%94%e0%b8%b2%e0%b8%a7%e0%b8%99%e0%b9%8c%e0%b9%82%e0%b8%ab%e0%b8%a5%e0%b8%94/#sub12)
ไฟล์เหล่านี้ถูกกันไว้ใน `.gitignore` แล้ว และ `tools/validate-data.mjs` จะฟ้องถ้ามีไฟล์เกินลิมิตหลุดเข้ามา

## Contributing | การมีส่วนร่วม

รายละเอียดทั้งหมดอยู่ที่ [CONTRIBUTING.md](CONTRIBUTING.md)
หรือใช้ฟอร์มที่ <https://hpc.in.th/submit/> ซึ่งจะสร้าง GitHub issue ให้อัตโนมัติ

- **GitHub**: [hpc-th.github.io](https://github.com/HPC-Thailand/hpc-th.github.io)
- **Data Updates**: ส่ง pull request แก้ `data/systems.json` เพื่ออัปเดตข้อมูลระบบ HPC
- **Language Improvements**: ช่วยปรับปรุงคำแปลใน `data/ui.json` (ข้อความ UI)
  และในไฟล์เนื้อหา `data/timeline.json` / `data/systems.json`
- **Timeline Updates**: เพิ่มเหตุการณ์สำคัญใน `data/timeline.json`
- **Documents**: เพิ่มเอกสารเก่าใน `reference/docs/` + `data/reference.json`
- **Corrections**: แจ้งข้อมูลที่ไม่ตรงกับความเป็นจริงได้ที่
  [issues](https://github.com/HPC-Thailand/hpc-th.github.io/issues) — โดยเฉพาะถ้าท่านเป็นเจ้าของระบบ
